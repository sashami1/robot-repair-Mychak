## Щоденник розробника

### Запис 1. Юніт 1: Персонаж і рух

Під час виконання першого юніта я опанувала такі речі:
1. **Створення сцен у Unity:** Створила нову сцену `MainScene` та налаштувала ієрархію об'єктів для рівня.
2. **Робота з Tilemap:** Налаштувала сітку та підлогу рівня через Tilemap, встановила `Pixels Per Unit = 64` для правильного розміру спрайтів.
3. **Сортування шарів (Order in Layer):** Виставила `Order in Layer = -10` для тайлмапа підлоги, щоб персонаж завжди відображався поверх неї.
4. **Створення 2D-персонажа:** Додала спрайт `PlayerCharacter` на сцену та налаштувала його початкові параметри.
5. **Написання C# скрипту:** Створила перший власний скрипт `PlayerController` та прив'язала його до персонажа.
6. **Зчитування вводу (Input):** Навчилася отримувати команди з клавіатури через `Input.GetAxis("Horizontal")` та `Input.GetAxis("Vertical")`.
7. **Подвійне керування:** Налаштувала `MoveAction` для одночасної підтримки стрілок клавіатури та клавіш WASD.
8. **Кадронезалежний рух:** Використала `Time.deltaTime` при обчисленні позиції, щоб швидкість руху персонажа була однаковою (3 одиниці на секунду) на будь-яких ПК незалежно від FPS.
9. **Контроль версій (Git & GitHub):** Опанувала фіксацію змін через коміти та завантаження проекту на GitHub.



##  Запис 2. Юніт 2: Оточення та фізика

### Що було зроблено:
- **Налаштування рівня та тайлмапу:** створено ігрове поле з підлогою та водоймами, додано бордюр.
- **Сортування спрайтів (Y-sorting):** налаштовано `Custom Axis (Y: 1)` у `Renderer2D`, виставлено Pivot у ноги персонажу та в основу декорацій, щоб персонаж міг заходити за об'єкти.
- **Фізика персонажа:** додано `Rigidbody 2D` (`Gravity Scale = 0`, `Freeze Rotation Z`) та `BoxCollider2D` (тільки на ноги).
- **Колайдери оточення:** додано `Tilemap Collider 2D` + `Composite Collider 2D` для води, вимкнено колайдери для підлоги (`Collider Type = None`), додано колайдери на префаби декорацій.
- **Оптимізація руху:** перенесено логіку переміщення в метод `FixedUpdate` із використанням `rigidbody2d.MovePosition()`.
